# Security policy

## Supported versions

Until the first stable release, security fixes are made on the latest published
`0.x` version only.

## Reporting a vulnerability

Do not open a public issue for a vulnerability. This project accepts security
reports through GitHub's private vulnerability reporting for this repository.
If that feature is temporarily unavailable, wait until it is available rather
than disclosing vulnerability details in a public issue or discussion.

Include affected versions, platform and OS version, a minimal reproduction, and
the potential impact. Never include real Wi-Fi credentials, proof-of-possession
values, BLE captures containing secrets, or production device identifiers.
